The big idea

Git tracks versions of a project. GitHub hosts Git repositories online. You can clone a repository to your computer, create a branch, edit and debug code, stage and commit changes, push commits to GitHub, and merge finished work.

Clone→Branch→Edit & Debug→Stage→Commit→Push→Merge

    Quick command reference
    Common distinctions
    Save ≠ Commit
    Save writes files; commit records a staged snapshot in local Git history.
    Commit ≠ Push
    Commit is local; push shares commits with a remote.
    Clone ≠ Fork
    Clone creates a local copy; fork creates a separate hosted repository.
    Push ≠ Merge
    Push uploads branch commits; merge integrates branch histories.
